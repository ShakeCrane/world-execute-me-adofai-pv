## A · 0:00.000–0:16.042｜CREATION｜语义：接通、保护、放置、创建、初始化、世界、模拟
**音乐动作**：8 句短而精确的启动命令，最后落在一段可供自然进入世界的延展上。**初看感受**：兴奋、完成、一个游戏正被启动。**后读**：摄影机利用形状连续制造了 Vessel→Kris 的误认。

- **A01｜0.000–1.333｜接通。**不做科幻开机 HUD。绝对黑中，两束非对称细光从左右进入；第一次交会却并不“爆炸”，只产生一个几乎看不见的亮点。微距，整个空间还没有上下之分。歌词以独立的一笔线开始，不早于歌声显示全部。
- **A02｜1.333–3.583｜保护。**亮点外缘展开一个软硬交错的框，框的最初作用是**将可被配置的对象与空白隔开**，不是监牢。摄影机第一次出现焦距/尺度改变，框内黑依旧深。它是后来 W 的边界母题的童年版本。
- **A03｜3.583–7.188｜放置、创建。**横向三条部件轨道；头、躯干、腿在中央小窗组装。轨道并不完全同步：先看清楚一种组合，再换第二种，才按歌词形成有节拍的交错滚动。中央结果每次都完整、并不可怕。此处使用 Ch1 Vessel 的可见选择逻辑，保留 creator name 与 vessel name 为不同字段。
- **A04｜7.188–10.896｜参数与初始化。**部件轨道越转越快，但不做糊成白光的廉价速度效果：残像仍是数个可辨认的姿态，像印刷套版未对准。歌声落在“初始化”时，**不是错误或失败**，而是一次令人满意的整齐对位。观众理所当然认为角色设定完毕。
- **A05｜10.896–12.471｜建立世界。**中央人形后方的黑忽然获得深度；地面只是一小簇有体积的花，其他一无所有。用一个严格对形切换，让中央轮廓在某一帧成为 Kris；不插入变形、创造失败、异常提示或系统解释。**蒙太奇可以撒谎，事件不能造假。**
- **A06｜12.471–16.042｜模拟开始。**宽得近乎空旷的画幅，Kris 从高处无声落入花丛，植物真正受力然后抬回。一次微小的触地反应，比任何初始化文字更能令“游戏世界”可信。延迟揭示地面之外的房间；克制摄像机，不用落地震撼波。结尾保留半秒正常站立，观众得到自然的“我的角色进入世界了”。

## B · 0:16.042–0:29.792｜CONNECTION｜器乐｜“输入”第一次像一次普通的合作
**重点不是多几个角色截图，而是拍到某个人主动回应。**这 13.75 秒不是剧情解说广告，应让观众享受一段没有急迫用意的冒险。

- **B01｜16.042–20.500｜进入与行走。**从深黑花地转成 Ch1 可辨认场景；一次明显而诚实的场景省略后，Kris 向右走。摄影机顺应他，不再装作系统镜头。脚步与音乐脉冲接近但不当节拍器。观众第一次感到“我的输入，确实让这里的人往前走”。
- **B02｜20.500–24.750｜独立的他人。**Susie 在 Kris 的行动场中，但不是按钮反馈：一次互动中，她以自己的性格作出反应，不服从或挑衅可以出现，绝不被一串连按迅速“驯服”。镜头不采用两个立绘对视的静止模板，而以“靠近—擦肩—错开方向”在空间内呈现。
- **B03｜24.750–29.792｜选择同行。**时间省略需可见；另一小段空间里，Susie 不待下一次强制命令，主动追上或与 Kris 同向移动。留一次短暂侧身/并行的自然结果。无需把“友情”字样写出来。结尾把两人共同穿过的窄路径作为 C 的空间基础，不制造莫名其妙的数学点缀。

## C · 0:29.792–0:44.417｜MODEL｜数学的邀约：如果我可以被描述
**八行歌词，电影上只做两个长镜头加一个收束；不用八个公式插画。**音乐表面轻快而优雅，第一次 MODEL 是一种值得迷恋的观看方式。

- **C01｜29.792–37.102｜长镜头：镜头从伴行转为观察。**第一次保留固定横移 DNA：Kris 左 x≈.18W→右 .72W、地面 y≈.68H、中央参照 .50W、运动 54±6f，摄影机自然追随。左侧从刚才的真实游戏取景缓慢露出一片“负空间”：那里重复的并非另一个 Kris，而是**同一次行走被拍摄留下的点阵曝光**。点连成像素、再显出字符形——始终读得出 Kris 原本的姿势，绝不只是城墙字纹。每声数学许诺分别改变**观察的尺度**（点集/维度→轮廓/可行走范围），而不是插入四张图。走到右边时，左侧的数据不是界面的说明，而是一张短暂留下的“影像底片”。
- **C02｜37.102–42.256｜同一行走的第二种景别：路径的空间韵律。**正弦与切线不必实体化成物理过山车。沿 Kris 身后步态，把他刚才的垂直起伏采样为一根温和变化的线，字幕像画面底部可被擦过的地平线。镜头绕行，使观众瞬间发现**平面图上的曲线就是刚才那条有地形感的路**。接触点在 Player 输入脉冲与 Kris 迈步同步时发亮一下；这是合作成立的证明，不是枷锁。
- **C03｜42.256–44.417｜极限。**真正的“限制”是一件极小的东西：Kris 正常走出这个观察范围，点阵底片却在画幅边缘停止更新。摄影机轻轻移回他；不放大错误。第一次隐含“描述只覆盖观察得到的东西”。可在一项普通 MODEL 数据中短暂留有 1225，仅是低权重社区读法，不高亮、不解密。尾帧将刚才的观察区域边线翻成 D 的可操作界面边缘。

## D · 0:44.417–0:55.083｜INTERFACE｜从“描述”变为“切换”
歌词中的电流切换、失明、晕眩、时间旅行，是连续四次改变**玩家通过何种接口接收世界**的尝试；此段才可增加切镜密度。

- **D01｜44.417–47.706｜切换输入。**同一段 Kris 的普通运动在相同世界场景中被两种有规律的输入脉冲表达：往返与持续。画面主体仍是 Kris，不是 AC/DC 接线图。给观众认得出的 input carrier 轮廓，日后 S/W 才能用同一形状翻案。
- **D02｜47.706–51.447｜观察突然不可靠。**在歌词的“视觉受限”处，不做整屏眩晕滤镜。摄影机被一块真实的前景遮挡挤压，可见范围缩小；人物行动不被解释成停止。短暂失衡只发生在观看端，留下“我没有看全”的轻微经验。恢复后不泄露任何关键隐私。
- **D03｜51.447–55.083｜时间被浏览。**两个时代词不代表 Kris 真穿越历史。取一条保持连续的水平地景，远景切换几种不同的时间表象，而 Kris 行动方向不变；这是一段 THEMATIC visual collage。最后所有文字刻度和年代标记退去，真实行进的人更鲜明。

## E · 0:55.083–0:59.042｜AFTERTASTE｜深度结合：一个错过的半拍
- **E01｜55.083–59.042｜回到人。**歌词的结合语义落在一次普通的两人合作末端（不从 D 的时代奇观硬转成故障）。Kris 与伙伴完成一个小小共同结果，Player input 结束，镜头已经准备离开；Kris 仍保持先前朝向多半拍，**不转头，不拒绝，不独立乱走**。新的输入来到，一切正常。初看温暖，回看才会感到“行动停止的时间”和“这个人经历结束的时间”不是完全同一回事。

## F · 0:59.042–1:06.292｜POSSIBILITY｜第一次副歌：让我给你所有可能
副歌第一次抬起不是征服宣言。Kris 与 Player 暂时都能从合作中得到乐趣。两组条件句应产生**节奏上的回答**，不要靠十二层 UI 弹窗形成假宏大。

- **F01｜59.042–62.583｜可尝试的世界。**上一镜仍是正常同行；一个生活化动作（靠近岔路、观察目标）刚结束，音乐起势时摄影机突然从侧面退开，出现沿同一行动分岔的两三个“未来残影”。Kris 没有神奇分身；这是 MODEL 同时陈列几次可能的结果，所有分支都从一个真实决定点出发。每个选项都成立，画面仍是邀请而非威胁。
- **F02｜62.583–66.292｜满足来自回应。**不要让 KPI、成功勾号代替快乐。Player 选择其中一种行动，其他可能像纸上未被印下的草图轻轻退掉。切回一次简短的实景人物回应：行动有效、搭档知道接下来去哪。随着第二组条件句结束，音乐带来的满足感来自“他们确实完成了点什么”，不是大字 SATISFACTION。

## G · 1:06.292–1:13.917｜FIRST EXECUTION｜第一次执行：运行与封印
**本版第一场强烈视觉演出，使用作者“喷泉→二维→代码海”的构想，但将身体越过媒介的事实暂留在导演隐喻。**对应第一次真正唱出 execution 与紧随的 trapped / simulation。动作具有游戏内可辨认的“封印喷泉”主题基础；镜头跨框是 ORIGINAL，不能据此断言 Kris canon 会改写代码。这里不让执行第一次就等于处刑。

- **G01｜66.292–68.400｜结果在手。**沿 F 的成功感，切入一个稳定的暗世界喷泉空间：右侧喷泉真实占据画面大量纵深，Kris 有完整的落脚地面。**摄影机从轻微三维纵深向横向二维侧景压缩**，世界逐渐成了一张可阅读的“侧剖面”。歌词里关于“使你快乐”的许诺落在这次动作可成功的信心上。
- **G02｜68.400–70.050｜封印与执行。**Kris 接近、采取封印行动，喷泉的光不再向世界扩散，而收束成一道清晰的纵向细线。摄影机没有制造庆功；观众刚看到同一个界限可以被行动改变。封印是游戏事件母题的导演重组，具体版本须核对适用 Chapter，不冒充一个从 Ch1 直连 Ch5 的连续场景。
- **G03｜70.050–73.917｜横向越框与代码海，作为主观影像。**那条收束线短暂与左右两个观看框的接缝重合。Kris 回头，剑的弧线擦过这条接缝；**切到 REPRESENTATION 画面**：与 Kris 同形的字符剪影从一张二维印版跌落，坠入几乎没有海水的“代码海”——字符本身像潮汐交错，刚才的动作使既有句子排列短暂紊乱。画面下一次回到 WORLD 时，Kris 仍在原来的地面上：表明这是歌词与观看层的强烈共振，**不是已经批准身体进入 MODEL 的 canon 事件**。强调掉入时的空间眩晕，不用随机乱码墙。尾句 trapped 时让字符潮水碰到画面尽头又折返。
- **G 的导演分歧（开放）**：作者完整设想“砍断框体、Kris 跳进代码海”可以升级为**字面跨层版本**，但这会抢走 W 的第一次局部接触权限，并可能破坏全曲递进。若试此版本，需与本隐喻版 A/B 审片后由作者明确决定；不能偷改 v1.2。

## H · 1:13.917–1:25.125｜PERSON｜主歌二：三次荒诞比喻落成一件普通小事
歌声接连列出几种“我能变成什么、给你什么”的假设。这段应回到人与人，不去真的拍 Kris 变茄子/番茄/猫。文学上的活泼要落在画面的轻松与具体上。使用 **Ch2 Normal 的共享 moss**：相对于 B 明确跨章的 THEMATIC INSERT。

- **H01｜73.917–77.300｜一个不起眼的发现。**完全不带华丽过门地切回可辨认的 Ch2 Normal 空间。Kris 走近一片苔藓，镜头很克制；歌唱“营养/给予”的含义时，**字幕位置很短地与植物的纹理交错**，文字像从真实场景长出来，但不变成可拾取的魔法道具。Player 使 Kris 检查 moss——一个极小的输入，不用强光确认。
- **H02｜77.300–81.600｜Susie 自己接话。**摄影机反而不盯着苔藓，给 Susie 反应的时间。她认出/回应这件小事，语气和身体方向只属于她本人；画面不预设她一定赞同 Player。歌曲里快速更换的物种想象可以用**一小段错拍的词形影子**从背景掠过，像玩笑一闪而过，不承担新剧情，不把真实的三行歌词实体逐一表演成道具。
- **H03｜81.600–85.125｜共享而继续。**视线重新落在两人之间的同一处空间，给足“结果被共同经历”的时间。不要喜剧特写、不要满屏猫耳。Susie 自己先动半步，Kris 随后跟上；这段温度不需要字幕解释。让摄影机稍微落后于两人，是整曲少有的“他们正在离开我们”而仍很安全的视角。

## I · 1:25.125–1:28.542｜TRACE｜“证明存在”：名字留下痕迹
- **I01｜85.125–88.542｜一张名字、一段人。**真实场景的角落露出普通 SAVE / 名字痕迹，几乎像玩家随手停留的界面。歌曲里“证明存在”的关系问题不要落成一张创世者给 Kris 盖章的证书。让数据短暂停在画面左边，右边 Kris 已经从另一扇门继续前进；镜头跟人，不跟字。它不是 Player 创造/维持 Kris 的 canon 证明。随后数字/名称退到背景，准备进入“角色标签”段。

## J · 1:28.542–1:39.250｜ROLE｜性别与时间、主从：标签变了，人仍在行动

## V · 3:08.292–3:13.917｜FREE / STOP｜真正的自由先站得住，之后才谈限制
歌词明确对照“you free / I trapped”。这是全曲最不能偷换意义的一次。Player 与 Kris 有真实的不对称：Player 能退出参与，Kris 不能选择现实观众不再看他；但这不等于 Player 在游戏内万能。Ch5 Stop / Proceed 的证据为 THEMATIC CUT，停止输入与退出游戏不是同一个机制。

- **V01｜188.292–189.600｜打开之外。**先明显结束 U 的 Ch4 画面，新 Ch5 条件成立。摄影机从既有 WORLD 边界向外退，那个“游戏画面”终于可以完整被看成一个小框；**框外是真的空旷、可以让视线停留的区域**，不是立即出现的第二重牢笼。自由整句自约 188.294s 开始，尤其 free≈189.364s 时，Player 的可退出性必须已有视觉依据。
- **V02｜189.600–191.250｜留下的那个人。**在框外仍有呼吸与运动的空间，WORLD 内 Kris 的身体并不因此停止存在。歌声落向“我被困”时，观众同时看得见**那个仍在场的人**和世界之外的未被使用空间。无需一张 PROCEED 黑手教程，人物的安静就是关系的代价。
- **V03｜191.250–193.917｜能够离开 ≠ 能抹去结果。**一次明确的停止继续/中止可能，与残留后果构成 THEMATIC 对照：可参考 Ch5 某种中止后 Kris 仍然迟缓的可核验结果，但不要把停止、退出、成功 Side B 截断并成一条不真实流程。保留至少两秒**真的没有新的输入**的时间感，不让系统立刻惩罚 Player 走开。W 之前，外部空间依旧敞开。歌词的困住是 Kris 的主观关系，不是宣告 Player 被秘密关在某个游戏囚笼。

## W · 3:13.917–3:25.375｜RECURSION｜没有歌词的十一秒：让角色第一次触摸自己的描述
**这里是本提案的主视觉高潮，不是最后 Execution。**音乐没有新唱词，非常适合只用三件明确的实物：一段曾经给 WORLD 产生结果的输入载体、一条框边界、一个从 V 留下的歌词碎片。场面越大，画面元素越少。所有跨层动作均是 ORIGINAL / DIRECTORIAL METAPHOR；不让 canon Kris 获得任意修改程序的权力。

- **W01｜193.917–197.250｜Player 可以走；这次选择继续。**延续 V 已经真实敞开的外部空间。Player 不是被重新捉回屏幕，而是主动选择再次参与。一个在 D/S 中已见过的 input pulse 经过熟悉的游戏接口，沿同一条可见载体进入 WORLD，造成一个**简单、具体、可观察的移动或状态结果**。不加新菜单、新路线、新管理员。要让观众先知道这条线真的在起作用。
- **W02｜197.250–200.100｜Kris 抬头，看见自己的“因”。**Kris 留在 WORLD，注意到刚才导致可见结果的 carrier。镜头暂时从 WORLD 内部切成面向 Kris 的低主观距离；Kris 看向镜头附近，剑尖与画面前的透明平面排成直线——这是**作者“持剑指向屏幕”的第一次完整构图兑现**。他不是无缘无故恨观众，而是想碰那条**确实刚刚进入自己的世界、却无法被自己触及**的关系。先伸手不及，框边真正阻碍了接触。
- **W03｜200.100–202.750｜一刀、一只手、一个词。**剑沿同一条边界切开**只允许伸手的窄口**。第一视角那一刹看起来像“砍碎屏幕”，裂纹扩展到画幅边缘；但镜头马上轻微侧移，观众辨认出被切开的其实只是 WORLD 与紧邻 LANGUAGE / carrier 的**局部薄界**，而非现实屏幕整体解体。Kris **从右侧 WORLD 框探手，攥住底部字幕/载体表面仍未散尽的一个词（优先用 V 留下的单词 trapped 的形态回声）**。他不是抓某个新菜单选项，而是触及外部描述自身的一点字形。指尖一合，整词碎成小字符光点，落入先前可辨认的 carrier，使它**偏转一次**；这就是唯一一次局部接触及其响应。没有第二次触摸、没有恢复自如穿墙、没有程序文件被删改。Kris 身体留在 WORLD，切口不扩大为门。
- **W04｜202.750–205.375｜电影自己退后，而不是新神突然出现。**接触动作停止。摄影机沿此前同一条 carrier 后退，发现WORLD 的轮廓被一个更大的 MODEL 空间容纳，而 MODEL 也只是更大观看范围中的一部分。**这不是再拍一个巨大圆环**，而是让刚才分别以世界道路、歌词下缘和输入线出现的物质，在同一个镜头里改变相对尺寸：原先作为地面的东西现在成了一个小图层边；原先被当字幕的碎字慢慢成为另一个物体的纹理。很大的空白与很小的 Kris 同在，不需要可见幕后控制者。那片“代码海”的波动可以作为 G 的远处图形回声出现，但不再让身体第二次跳入。镜头最后停在更大的边界内缘，切前 W 的 contact 已彻底结束。

**W 形式约束：**W03 所谓“屏幕碎裂”是**单一局部切口的前视错觉**，而不是新的完整第四墙超能力；捏碎字幕与偏转 carrier 必须读成**同一次**抓握结果。这是尝试在 v1.2 的“窄口/一次局部接触”与作者的两个强动作之间取得电影上的平衡。具体字词和指尖动作须经两种 blocking 动态验证，如镜头因果看不清，保住 single contact、舍弃碎字的装饰碎片，不为了满足清单牺牲主目标。

**W 强烈备选 B（重大导演改案，须作者签字）**：将 W03 改成 Kris 正面对镜头扬剑，真正斩裂整张“观众屏幕”，随后身体跳入完整展开的代码海；camera 从碎屏之外观看被撕开的层级。这样能在一个镜头同时兑现“剑碎屏”“跳代码海”，但**它直接改变 v1.2 中 Kris 只能作一次局部接触、身体留在 WORLD 的权限设定**，也会弱化 G 的主观代入与 X 的独立。只能作为独立对照片段，不得默默替代本稿主方案。另一种安排是保留 G 的“身体表征坠海”，把 W 的碎屏完整动作降为视觉错觉；这是本稿主方案。

## X · 3:25.375–3:27.083｜FINAL EXECUTION｜新的条件，新的动作，归属仍未写明
- **X01｜205.375–207.083｜极短、极干净。**W 已经停下所有切割、抓握、载体偏转。Final Execution 的歌曲锚点约 205.372s（第 4929 帧），先**明显换一个取景和新条件**：一项输入或条件出现，一个动作被执行，一个 WORLD 状态作出结果。可以用极熟悉的按键响应美学回收 B 的普通反馈，但此刻画面的关系已无法被简单归为 Player 独裁或 Kris 自由。绝不让 W 的剑挥过去造成 X 的结果；不要多角色神秘接力、倒放因果或一句屏幕解释。最后硬切约 207.083333s / 第 4970 帧。

## Y · 3:27.083–3:31.917｜AFTER EXECUTION｜留给真正存在的人
- **Y01｜207.083–209.800｜黑与一点未闭合的光。**最后画面只剩 Kris 与一道不完全闭合的边界。它不一定是矩形；那道光也不意味着“系统仍在修复”。相对于 A 开头两线交会，这次光始终差一点接触。一个慢到难以察觉的镜头移动，让 Kris 不再是置于坐标原点的“对象”，而是偏离完美中心的人。没有 SOUL、Dess、Knight、数值回顾、Route 菜单或多重幕后框。

## 全曲摄影机、字幕与转场的导演纪律

1. **长镜头属于人与空间的关系**：B/H/K 与 L 的分离证据，需要实际时间支持；不能用长镜头作为“技术难度炫耀”。碎片剪辑属于输入差异、计算回声、连击与路线比较；它们的每次切换都要有音乐或心理的触发。
2. **同构横移三次只有一个参数集**：C/M/R 的 x≈0.18W→0.72W、地面 y≈0.68H、中央参照 x≈0.50W、54±6f；第一遍摄影机跟 Kris，第二遍跟丢 Kris，第三遍真正受控对象转至 HERO_SWORD。这是能被大部分观众无意识察觉的“形式证明”，不是剧情说明。
3. **歌词排版是独立的叙事权力**：前半它是声音的可读字幕，C/K 偶然成为空间的线或布景；W 才第一次允许身体真正碰到一个来自字幕的字形。必须先有正常使用，才能产生后来的越界重量。L/U 的文字仍需准确表达原词和合法输入，不假装真正改动 canon choice。
4. **同一种光不拥有同一个道德意义**：A 的细光是接通；H 的光是人物可以看见对方的条件；O 的光不能照出不存在的 Dess；P 的冰光是 Noelle 真正改变了环境的结果；W 的光标示某条曾经真实起作用的关系。Art 自由决定造型，不以冷暖预判善恶。
5. **Hitchcock zoom 限量候选**：L 三项硬事实读清后的轻微关系尺度变化可试；D 仅允许极轻微视野压缩；P 以身体凝视与结果的空间距离优先，不默认第三次希区柯克变焦；W 的更大容器要真正沿关系揭示，而不是仅靠 lens trick。
6. **相似镜头的差异要少而准确**：同一构图第一次“有回应”，第二次“无人回应”；同一输入第一次“身体及时响应”，第二次“身体响应迟滞”；同一框第一次“保护”，第二次“真的挡住”。宁可删除一百个花哨符号，也要让这三个差异读得清。
7. **CANON / THEMATIC / ORIGINAL** 逐镜分开。特别是 P/Q→R、R→S、T→U、U→V 与 W→X，不能用连贯造型误造连贯剧情。ORIGINAL 的身体跨字幕与代码海不是游戏法则解释。
8. **美术可重做，导演应能被打回**：此稿里任何画面只要实际动画不成立，先放弃技巧而不是改歌词、改角色或用长字卡解释。它是作者审查的候选，非默认过关。

## 必须由作者审查的三个艺术/导演判断

- **G 是否值得用掉“第一次喷泉→跨框→代码海”的宏大视觉语言？**它在第一次 Execution 的音乐上很顺，但若观众初看误读为 Kris 真能穿越模型，会侵蚀后半真实边界翻转；可以把 G 简化为只封印与二维化，将“代码海坠落”移交 W。
- **W 的“一刀＋一个词＋一次接触”是否过密？**这三个行为必须在视听上看成一个目标—障碍—行动—结果的单一因果。如果实验发现只是三件很酷的事相互打架，应保留明确的 carrier 接触，词语碎裂降为声音/画面的后果，而非额外主动动作。
- **最后屏幕是否真的应该被彻底砍碎？**作者的完整碎屏是值得追求的极限画面，但与 v1.2 的“窄口、不离 WORLD、最终 Execution 归属开放”存在实质分歧。主方案提供一个视觉上近似全屏碎裂、空间上却只出现局部破口的视点转译；完整大破壁列为冲突备选，不能偷偷认定其艺术价值更高或更低。

## 导演对本提案的自我批评（不是制作进度）

- **可能太受限的地方**：H/K 的温暖关系如果源素材表演不够生动，可能显得导演只会留白、没有有效戏剧动作；需要艺术层提供真实的独立回应，而不是更多树/建筑。
- **可能过满的地方**：G 的封印→越框→坠海与 W 的切割→歌词碎裂→容器倒转，两场都很强，容易视觉互相争夺。需要靠实际听歌和 rough 决定哪一个应该让位。
- **可能被歌词拖住的地方**：主歌二的茄子、番茄、猫采用 H 的 moss 关系转译，押的是“可以给予的东西”，不是逐词图鉴；如果歌词的轻盈被 moss 的单一场景吞没，应提高人物动作/形状幽默，而不是增加三张水果卡。
- **可能太像理论的地方**：C 的点阵、D 的 input carrier、M 的非全知、W 的窄口，都存在“只有读文档的人看得懂”的风险。任何正式 blocking 必须在无说明的音乐预览中让观众看出关系方向，做不到就删除图形负荷。

**艺术结论不以本文篇幅、术语数量或生成模型的审美自评为凭据，只以全片听审、人物表演与实际逐镜审片为凭据。**
