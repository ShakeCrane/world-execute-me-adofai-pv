## 一、导演层新增认识

- 不是简单「用 DELTARUNE 讲《world.execute(me);》」，而是借歌曲中的执行、语言、控制、描述与媒介关系，促使观众重新理解 DELTARUNE 的人物、Player 与执行权。
- **媒介不是装饰，也不是自然获得 canon 能力。** WORLD、MODEL、LANGUAGE 三框可以出现物质上的互相作用；INTERFACE 描述它们之间输入、观察、响应的通道/边界，不擅自作为替代三框的第四个固定舞台。
- 媒介的戏剧性来自**同一个形象或动作再现时改变了一个关键条件**：容器→界限→行动障碍→可触及对象；参数先描述身体、后暴露无法穷尽人物；歌词先是可阅读文本，后成为行动依托或可接触对象。
- 视觉状态变更必须与歌词语义、声音事件、人物心理和 Route 证据同时成立。**不允许酷镜头先行，硬找歌词。**
- 叙事最高约束仍是「双意志、单执行层、动态切换」「执行权不是所有权」；视觉反作用不等于 Kris 修改游戏代码、全能或在 canon 上拥有现实层超能力。
- 角色应先作为**具体的人**被观众感受：Susie 的自主合作、Noelle 兼有欲望和命令依赖、Kris 的保护/注意/身体行为；媒介的扩大不能抹掉这些关系。
- 以歌曲原有 **A–Y、211.916667s / 5086f@24fps** 为基础审查下一轮草案。分镜镜头数并不等于歌词行数，允许跨句持续、呼吸、碎片蒙太奇。

## 三、媒介叙事字段（用于逐歌词镜头单元，不替换正式 Shot Bible）

对每个有变化的镜头单元，记录：

1. **歌曲锚点**：真实歌词行/词、起止秒、持续的音乐动机/卡点；自动对齐必须标注“待听审”。
2. **歌词功能与情绪**：这句话此时是请求、条件、许诺、声明、重复还是质问；观众应先感到什么。
3. **关系 / canon**：Kris↔Player，以及 Susie、Noelle 等角色的条件与主动性；`CANON / STRONG INFERENCE / COMMUNITY READING / ORIGINAL`。
4. **镜头与 blocking**：画面起止状态、运动、空间/视点、转场；解释为什么不在每句强行切镜。
5. **媒介状态**：WORLD / MODEL / LANGUAGE 的边界是否分离、叠加、融合、反转，INTERFACE 是否允许通行。
6. **不可逆视觉事件**：例如描述开始作用于可见物、框从布景变为阻碍、歌词从字幕变成地形、人物首次触及原来不可达的文本。必须清楚它是**导演形象**还是剧情内 canon。
7. **认知差**：第一遍观众相信什么、哪些事实被隐藏、回看时如何重新解释。
8. **Art handoff**：服务哪种情绪及情感对比；不提前锁字体、色彩、shader 或材质。

**设计纪律：**没有新叙事条件的“多框、代码、光、碎屏、glyph、Hitchcock zoom”不是成立的视觉事件；宁可留一个真正可读的人物动作。

## 四、须保留的反例与危险边界

- Vessel 组装与 Kris 出现在残影之间的连接**可以成为蒙太奇谎言**，但不可写成“Vessel 生成了 Kris”或“系统生成失败所以 Kris 诞生”的 canon 事实；观众早期应自然误读，而不是立刻收到故障警告。
- Kris 在开屏黑暗落地/花丛中的形象可以使用，但不提前宣称 Kris 是刚刚被世界创造的，花也不是“只有它不可参数化”的 canon 公理。
- Kris 砍框、跳代码海、捏碎歌词、砍屏幕是**保留的作者镜头想象**；观众可以看到媒介跨界，但不能无证据断言 Kris 具备 canon 的改程序能力。
- 注意已锁定 **V 段 Player 相对自由先真实成立**；W 段原版导演方案为「窄口局部接触」，新镜头可以作为待比较方案，但不能直接以完整入侵 MODEL 替换正式封板。
- SOUL separation 不能解释成 Kris 的意志在此刻突然生成；正常合作也不是 Kris 没有意志。
- Noelle 的 Weird 命令不得简化为「LANGUAGE 第一次有作用」；RPG 语言早有日常功能，Weird 的变化是命令关系、选择与人物感受的异常升级。
- Knight、Dess、1225 等社区阅读可共振，不假装解开未定谜题；跨 Ch2/Ch3/Ch4/Ch5 的叙事比较必须标记 THEMATIC，不制造伪 canon 连续动作。
- 结尾 Execution 不唯一指向 Kris/Player/Route；「更大容器」不需要新幕后人格。
- 大胆视觉必须接受歌词和节奏的重新定位，不得为了满足整张创意清单而强行每条都进成片。
