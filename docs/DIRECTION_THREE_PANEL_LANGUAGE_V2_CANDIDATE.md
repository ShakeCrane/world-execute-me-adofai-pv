此示意只是描述复用空间，并不主张在原作外面再添加一圈大框，也不变更顶部标题 / 运行状态装饰。实际像素尺寸以原 engine 和镜头测试为准。**默认一帧内三框都在原位**，允许某框在器乐中保持低密度或空白，不要求每秒都在“表演”。

### RIGHT / WORLD：戏剧与情绪的唯一主叙事镜头

- **内容**：原作游戏角色、可核验情节（Vessel、SOUL、共享 moss、Noelle Weird、HERO_SWORD 等）、近景与远景、blockings、视点失误、环境光和戏剧节奏。Kris 始终是歌词中的 I，Player 是 you；Susie、Noelle 不轮流“代唱”。
- **运镜**：大景、平视、俯视、有限 3D→2D、正常跟随、固定构图三次同构横移、长镜头和碎片剪辑都属于**右框内部的摄像机**。观众不能在主体叙事仍发生时被迫在三个窗口“找 Kris”。
- **常态**：WORLD 不显示左侧的完整代码终端，也不大量吃掉字幕框。可有游戏内**原生** SAVE、choice、战斗 UI；这不等于左边 MODEL 已经渗入。跨路线用可见的 THEMATIC CUT，不能伪造同一连续剧情。
- **避免**：图解歌词名词、抽象 HUD 连续覆盖人物、为了让每次副歌都升级就不断破壁。

### LEFT / CODE & MODEL：一种“描述/操作视角”，不是剧中的全知幕后神

- **三种基础材料**：（a）同一时刻右框动作的**参数投影**：位置、朝向、状态、受控对象、输入频率；（b）独立于右框的**几何/点阵/ASCII/代码海**：能独自建立优美空间感，不只是黑底打日志；（c）**操作与结果之间的关系图**：输入脉冲、执行轨迹、延迟、分支、合法 Route 门槛、命令重复。
- **运镜与表演**：终端镜头也有景别：点的微距、数据的纵深、镜头在代码字符构成的“海面”上低空移动、抽样视图切为字符肖像、一个值被锁定时突然静止。**左框的字符海从影片开始就有丰富的艺术生命**，它不是到 G 才突然凭空冒出的新空间。
- **认知边界**：只有可观察/推断的信息，必要时出现 `?` / `unknown` / 缺失采样；不冒充可以读 Kris 意志、Dess 位置或 Player 现实身份的真实游戏内部代码。不要把任意伪代码呈现为游戏官方源码。
- **剪辑节奏**：右边动作重要时，左边退成非常少的状态线或低对比静止；右边空间/情绪悬停时，左边可以独奏一次模型发现。**不是左右两部影片争夺注意力**。
- **左框自然的意义演化**：早期看似精确、可靠、令人好奇；中期可计算的身体 ≠ 完整的人；后期能够明确报告输入/身体 mismatch，却无法提供人的动机答案；越框后代码海被打乱，是一次局部视觉事件，不是系统接收了新的 canon 程序。

### BOTTOM / LYRICS：歌曲语义与第三种视觉质感，不是第二套剧情

- **实现尽量原作式复用**：`continuity_full_v2/words.py` 的逐词 onset、逐字出字、延长元音、句尾停留和长器乐空白渐隐；默认是一条稳定的窄横框，不切成独立的歌词影片。
- **DR 主题点缀**：少量游戏对话框边缘语法、SOUL 红色指示点、选择光标、SAVE 星点/小像素花纹，作为**字形语义与节奏的微弱装饰**，不假装源游戏里的真菜单；每次至多一个焦点，不用大量新增彩色标识或字体跳舞。
- **文字功能**：歌词是歌手在唱的语言，必须精确、可读、不断声；关键词强调随音乐起音，不任意改词义。可以给 `I / you / execution / free / trapped` 等持续一致的较小视觉规则，但**不是每出现一次就演一件新效果**。
- **器乐**：空白、最后一个词缓慢消失或保留极弱提示字符皆可；不强迫下框在 O/W 的器乐时出现本来没有的歌词。
- **越界前史**：字幕先长时间安分作为字幕；当 Kris 真的从右框抓下框中的**一个被唱过或留下的词**，观众才理解他打破了什么。在此之前，歌词意象可以呼应右侧空间，但**空间里的路仍是右框自己的视觉艺术，不能把原下框直接拆掉移进场景**。

### 三者的关系：正常仅有“信息呼应”，没有物理通行

右框里 Kris 往右走 → 左框可显示位置变化；下框唱到给予/定义 → 左框变化一次采样方法；右框 Noelle 感到力量 → 左框记录可观察效果。这些是**两块不同舞台对同一个事件的翻译**，不是三块舞台物理融合。

从导演语法看，三框分别回答：
- 右：**发生了什么？一个人感觉如何？**
- 左：**发生的事如何被描述、预测和操作？有什么永远无法被表示？**
- 下：**此刻歌在对谁说话，许诺、疑问、要求或重复什么？**

**禁止常态互相抢画幅、互相投影为全屏、三框无理由拼图变形。**“共同语义”主要通过歌曲同步与语义联动达成；作者明确授权的越框行为才升级为物理联系。

## 四、三类镜头如何具体拍：框内的电影语言与例外空间因果

### 4.1 左框抽象镜头语法（不是滚动代码壁纸）

| 镜头语言 | 左框摄影/视觉动作 | 正确使用时机 | 应避免的内容 |
|---|---|---|---|
| **SEMANTIC DEPTH（代码海纵深）** | 多层字列以不同速度向纵深移动，近字缓、远字密；一条可读参数流固定在前景，使抽象画面有深度和稳定锚点 | A 的参数选择、C 的采样、G 被人物冲散前 | 纯无限下落数字雨、任意像素辉光、不可辨认的乱码 |
| **SAMPLING（采样）** | 每采集一次右框 Kris 的动作，只增加一个点或一块字符轮廓；摄像机近到能够看到采样精度，随后退至整体构图 | C 的数学歌词、S 的输入/身体时差 | 把 Kris 完全替换成无源抽象符号 |
| **SPLIT TRACE（输入轨迹与身体轨迹）** | 两条可读的细线随时间漂移；同步时紧贴，分离时错开；线中断表示“未观察到”，不是说明真相 | E 的半拍、L 的离体、M 的跟丢、R 的受控对象切换、S 的迟滞 | 假定所有身体行为都可归因为单一程序命令 |
| **CONDITIONAL GATE（条件门槛）** | 输入落在已有可行条件或无法通过的阈值上，像一个狭窄却精确的数学开口；不是“系统坏了” | N Weird Route、T 的请求接口 | 进度条、百分比、假 debug log、删世界威胁 |
| **EXECUTION RHYTHM（重复执行）** | 同一视觉词形、同一轨道发生多次，但间隔与人物感受有关：犹豫→动作→反馈→再次请求 | P/Q，偶尔 X 最后一次回声 | 十二次击杀计数、过密闪屏、机械增加命令条 |
| **HOLD / UNKNOWN（静止与不可知）** | 大片真正不动的字符海，偶尔只动一个光标；存在被保留但无法补足的空段 | H/K 右框人物优先、O 缺席、V 自由、Y 尾声 | 把空白做成等待加载或系统报错状态 |

左框的审美目标应该比以前的“参数装饰”更明确：**像一个有人格气息但不拥有人格的描述世界**。抽象本身有形态、远近、节奏、停顿；只有在有证据时才对应一个具体动作。可以让代码海漂亮，却不可让它成为从头到尾解释所有角色思想的字幕机。

### 4.2 右框的镜头语法

- **可信动作优先于设定**。右框是人物故事：站姿、身体重量、注意方向、衣物运动、周围物体的真实反应优先。即使画面在做 3D→2D，仍必须辨认人所处的地面。
- **空间连续性是必要条件，不是花招**。像 C 的左→右横移、H/K 的同行、L 的硬事实都要求一个可追踪的镜头，不用代码海配音解释。
- **跨章剪辑应当诚实**。H 的 moss 与 B 的 Ch1 不是同一天无缝发生；P/Q→R、R→S、T→U、U→V 必须是可识别的切换，右框中不能以同一背景或手势接成伪 canon。
- **情绪的真正高潮可能来自“没动”**。K 的共同反应、L 的安静、O 的空处、P 中 Noelle 亲自确认力量、R 的一个保护动作，应被留时间。左框此时收束，不允许数据视觉抢戏。

### 4.3 下框歌词的有限导演变化（永远能认出是歌词栏）

**常态**：逐词歌词条，保留原作字体尺度、行内可读节奏、token 强调与正常停留。修饰只响应唱词语义，不替代唱词。每首完整歌曲维持同一空间位置，避免“歌词飞进地图→歌词框没了”的持续剧场化。

可以使用三项极小而有持续意义的 DR motif：
1. **红色点 / SOUL**：当歌词谈到 I/you 的关系，可以极轻地作一个位置或焦点标记，但不能让 SOUL 标记等同全部现实 Player。
2. **选项焦点**：在涉及条件、切换、选择的唱词上，出现一次类似选项光标的焦点；它是文本语法，不让下框变成真实可选的游戏菜单。
3. **SAVE 星点**：在记忆、名字、存在痕迹相关位置只出现极少数小点；不是把每一句歌词都弄成花哨 RPG 对话框。

**不要每句换字体，不每个 `execute` 都红色爆闪，不把 `free` 变成飞出框的文字，不把 `trapped` 直接扣成封锁整张画布的铁笼。**越是字幕长期可靠，W 发生的那一次字词实体化才有力量。

### 4.4 G 的跨框运动：需要真正理解的是“这是左右两个世界”

- **G0 / 66.292–68.400**：三框都完整。右窗内喷泉靠画右，Kris 在左；左窗的代码海在自己的窗里有规律缓慢运动，底窗唱词按时出字。
- **G1 / 68.400–70.050**：Kris 在右窗封印喷泉；垂直光束收拢，右窗二维侧景成立。左窗只轻微响应对应的模型事件，不会自发炸开。
- **G2 / 70.050–71.300**：Kris 回头**看向右窗左边缘**，视觉导向约 x=404 处的框线；手与剑的动作有一个准备姿态。不能让他看向整张屏幕中心后突然落到左边。
- **G3 / 71.300–72.550**：刀刃碰到 x≈394–404 分隔位置，**边界出现一条窄暂裂缝**；拍到 Kris 身体/同形影像从右窗跨入左窗。动作对象是两个固定窗口的分隔关系，右框的四条边仍可辨认。
- **G4 / 72.550–73.917**：左框的字符海因为“一个本不属于这里的身体”到来而扭曲。让代码层按照视差前后遮挡 Kris：一些字符在他前面被拨开，另一些在后面回卷。镜头可以短暂让左框成为注意力主导，但下栏不被波及。**后续 H 的硬场景切换恢复原来三框**，不是永久解锁穿梭权限。

此处跨框在画面上可以非常大胆，因为它经过了三十多秒的固定框架积累；若三框此前已经频繁拼接，这一剑会毫无力量。不同于 v1.2 W 的局部接触，G 越框属于作者新提案，应视为可竞争的**导演重大变化**，不能私自称为旧版已批准。

### 4.5 W 的歌词接触与观看镜头：明确它们为何不能和 G 重复

W 首要问题是**这道关系已经真实影响到 Kris，而 Kris 从没被允许触碰它**。此前有 G 左窗可跨，后半在 L/M/S 发现人与观察系统并不相同；所以 W 要针对**另一个方向**，不要让 Kris 重新跳入左边一次。

- **W0 / 193.917–198.000**：维持全片三框。Player 的继续通过左边已经建立的简洁接口脉冲产生右边一个实在的 WORLD 结果。底栏处于器乐空白。玩家有权离开，继续参与也仍经过游戏的操作边界。
- **W1 / 198.000–200.500**：右窗内 Kris 先追随脉冲的视觉路径，明白有一个看得见但够不到的外来影响。一个短特写中剑正对观看方向（作者原构想）。**这不立即造成全框碎裂**，首先是对观众观看关系的直视。
- **W2 / 200.500–202.500**：界限第一次实实在在挡住 Kris 的手。剑经过短准备从右窗内部触碰到临近下方的局部边界；**下方语言栏仅此一次能以一层特殊字词精灵留住 V 段 `trapped` 的视觉回声（非 W 当时新歌词）**。下框常规歌词显示规则不改，额外的回声词必须能被观众识别是“前文留下的同一个词”。
- **W3 / 202.500–204.500**：Kris 从右窗向下抓住它、捏碎；碎字只从被抓住的字母发出，不从整排字幕四散爆炸。**一次实体化行为产生一次局部字符后果**，左侧代码海可以有短促对应波纹，但其余区域保持固定。Kris 不能靠此删掉正规歌词、更改原作菜单或按自己的愿望改写 Route。
- **W4 / 204.500–205.375**：动作收束，手回到右窗，三个固定窗口再次完整。影片可在右框内部拉远/变换观察尺度，让观众意识到游戏画面只占整体关系的一部分；**不把外部假画布当作第四个永久舞台**。X 将以一个新条件、新执行动作和新的声学事件进入，不直接复用这次碎字波纹作因果。

**作者的完全砍屏版本仍保留**：如果最终决定 W2 不是局部触及，而是剑真正破坏全画布，那么这是对固定三框布局的**唯一终极例外**，需要反过来压低 G 的越框幅度、重新研究 W→X 的因果。此分歧尚未审核通过，不把候选 B 写成官方定稿。

## 六、导演审查结论（供作者决定，不作为定稿）

- **已经明确的**：三框基础几何与相对关系不可动；右框演主故事、左框演代码海/参数抽象、下框按原作歌词机制出词；绝大多数时候物理不越界；旧 v2 镜头是右框主线。
- **仍需审查的**：G 的跨框究竟身体完整跳入还是角色表示进入、W 的歌词接触在器乐如何读取、不脱离 v1.2“只一次局部接触”的边界时如何兑现正面碎屏，以及大跨框动作是否要放在不同歌词处。两项不能靠漂亮静帧自行被批准。
