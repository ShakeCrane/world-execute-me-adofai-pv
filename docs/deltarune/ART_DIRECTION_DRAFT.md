# Art Direction Draft｜World-Execute-Me-DR-PV

状态：**视觉语言草案，待网页版 GPT 与人工艺术验收；不是 Art Bible 终稿。**

依据：Castle Town / Kris 的 18 秒连续收束样片。本文保存可继续创作的结论，样片和试验代码可删除。核心叙事仍以 [CORE_STORY_BASELINE](CORE_STORY_BASELINE.md) 为准；不确定的剧情关系保持不确定。本阶段没有生成正式 Direction、Shot Bible 或歌词镜头映射。

## 1. Top Artistic Thesis

**以 DELTARUNE 为视觉母语，让二维世界被摄影，让界面成为可接触、可改写的空间结构。** 第一眼保留角色与世界的身份，第二眼通过摄影与层级关系显出本 PV 的表达。新增形式服务于输入、执行、边界等主题；能进入世界不等于拥有其中主体。

唯一判断链：顶层艺术命题 → **DR Anchor × Our Language** → **空间 / 像素 / 光影 / 边界** → 具体镜头选择 → 技术实现 → Art Review。技术能力不能跳过镜头意图。

## 2. DR Anchor

- Kris 使用真实 sprite 与姿态；保留轮廓、头发、服装、动作身份。
- 保留硬像素、黑色负形、符号化建筑、原场景的青蓝 / 紫 / 青绿色关系。
- 本样片的识别主干是中央城堡、两侧尖顶、庭院与入口道路；细节可以减，主干不能用通用奇幻城市代替。
- 输入端、世界、歌词初始身份清晰。UI、SOUL、战斗框等原作符号按正式镜头需要使用，不为了“更像 DR”全部塞入。

## 3. Our Language

摄影、折叠式景片、原像素的有意重排、有限色阶光、词进入道路、界面边框成为空间框架，共同承担新增表达。新增形体明确属于 **AUTHORED_EXTENSION**；不要求假装是原作隐藏房间。

样片以同一条边线贯穿：窗口 → 地面边界 → 立起的空间框架 → 三层共同结构 → 窗口。这样一个对象的用途变化，比不断新增特效更适合本项目。

## 4. Spatial Grammar

前景植被、中景道路与角色、远景建筑使用共同摄影机。真实 sprite 的脚底锚在地面，遮挡具有顺序；世界中的界面结构也要接受角色 / 前景遮挡。当前实现使用明确绘制顺序及角色 / 前景回绘，没有通用深度遮挡系统。

允许纸片、折面和设计过的非写实空间。黑色负形承担不可见区域，不用大量细节填满。镜头需要的道路延伸、折面背部和深度由作者设计；只有画面需要时才制作隐藏形体。

本样片 yaw 11→21→17°，轻推、横移后回收。它证明这条具体路径可用，**不规定其他场景的机位上限**。景片仍显平面，侧面造型仍粗糙；未来是否保留这种构造感，由镜头的艺术目标决定。

## 5. Pixel Grammar

像素是需要制作的资产。远景优先保住屋顶结构和窗光：删除低价值孤立点，给结构轮廓足够像素厚度；中央城堡与 Kris 保留较高身份细节。LOD 按元素意义选择，不能把角色、招牌和背景统一交给降采样算法。

本样片远景使用一套固定的整理版，不在运动中切换 LOD；它是场景专属派生资产，没有正式通用 LOD 选择器。Kris 使用原始四帧、nearest、整数尺寸和共享脚底锚；不采用上一轮 38 / 33 / 28 的大幅尺寸跳档。整个右窗逻辑像素按精确 2× 输出。

透视细线仍会跳变；五次角色尺寸变化各为一个逻辑像素。保留这些问题，不以模糊、插帧或光效覆盖。轮廓加强的粗细需要 Art Review，不能默认为所有场景的固定笔触。

## 6. Lighting Grammar

**先确定光属于哪一层，再确定它照到哪里。** 本样片中进入世界的命令标记与道路光使用同一个地面坐标；道路材质响应三档青蓝光，黑色 void 不受光，角色仍保留原作色彩。边框的亮边承担界面结构的存在感。

这是局部、符号化的照明。没有全屏色罩、bloom 或写实阴影承诺；没有确认 System 发光的剧情事实。是否进一步让光影响 Kris 或建筑，必须由具体镜头的表达决定。

## 7. Boundary / Fourth-Wall Grammar

| 等级 | 本样片的时间递进 | 可迁移的规则 |
|---|---|---|
| 分离 | 先建立三层和可行走世界；随后摄影开始 | 观众先懂每层的正常职责 |
| 渗透 | 前景越右窗；命令标记进入地面；一个歌词词进入道路 | 接触对象有来源、轨迹与落点；其他层仍可辨 |
| 反转 | 原窗口边线投影到道路，开始受空间关系支配 | 同一个对象改变用途；世界 / UI 的前后关系可互换 |
| 坍塌 | 地面框立起，左窗与字幕框短暂汇到同一结构；命令与当前歌词进入框面 | 短、集中、源于已有对象；保留角色身份，不靠随机 glitch |

最后回收边框、字幕与输入端。坍塌表示影像层级短暂共用空间，**不表示世界拥有独立人格、剧情失控、Player 进入 Kris 意志或管理员现身**。同样，竖框在此只是艺术测试，尚未被定义成正式剧情中的门或囚笼。

## 8. Strength Levels / Allowed Uses

建立段以 DR Anchor 为主，Our Language 轻。摄影与渗透可作为正常表现能力；反转需要明确的镜头理由；坍塌仅用于有铺垫的短暂重点，随后给清晰落点。整曲不应每镜都把四套语法开到最强。

正式导演先决定观众此时应理解什么，再选择边界等级、摄影幅度、像素细节与光源。不能因为机制已实现就提前揭示 Vessel / Kris、控制来源或尚未确认的故事答案。

## 9. What This Sample Confirmed

**是：视觉语言已基本收束，足以进入正式 Art Direction / Direction 阶段，通用技术研发可以收口。** 四套语法已在一条有建立、推进、接触、反转、合并与回收的连续样片里共存；不是四个独立演示。

样片完整解码为 18 秒 / 432 帧；开场世界稳定，真实行走与共同地面锚成立；前、中、远景视差有深度次序；越框后回收，界面结构可被世界遮挡。逆序求帧一致，同姿态 / 同尺寸的 395 对相邻角色栅格无额外变化。这些检查支持可重复制作，不能代替审美验收或宣称最终动态无瑕。

## 10. What Remains Unresolved

屋顶 / 窗光细线仍跳变，透视文字的可读性不足；地面延伸过简，折面背部仍偏技术占位；脚步未经实机速度 / 接触校准，源姿态留白仍有一逻辑像素。三层汇合的中途线条较繁，强状态的停留与回收节奏仍需艺术审查。

这些是后续**按镜头制作和局部修整**的问题，不要求再开展万能过滤器、完整游戏重建或大型 Film Harness。没有证明其他角色、地图、大角度机位或正式全曲质量。

## 11. What Requires Human Art Review

1. 是否接受黑色负形中的折面 / 景片空间感，以及当前轮廓加强和植被放大的力度？
2. 边框落地、立起和三层汇合是否构成合适的第四面墙语言？竖框的门 / 限制感是否过早、过强？
3. 当前局部青蓝光与低细节地面是否足以成为艺术起点？正式镜头应保留多少原作平光与细线？

验收后再确定正式艺术与导演选择。本草案不自动升级为终稿，不自动启动全曲制作。
