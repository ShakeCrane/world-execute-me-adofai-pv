# DELTARUNE 剧情核心底座

> 状态：LOCKED BASELINE  
> 用途：后续剧情分析、歌词理解与最终分镜讨论的共同起点。  
> 规则：这里只保留直接事实、最小必要推论，以及用户明确确立的项目公理。除非出现新的官方/游戏内证据，或用户明确修改，本文件不随讨论漂移。

---

## 1. 事实层：目前不能绕开的游戏内事实

### Vessel 与 Kris

- 游戏开场允许玩家配置一个 Vessel，包括身体部件、若干参数与名称。
- 随后该 Vessel 被告知将被舍弃，叙事切到 Kris。
- 现有画面没有显示 Vessel 被“初始化成 Kris”。二者未来是否还有更深关系，未知。

### Player / SOUL / Kris 并不完全重合

- Kris 可以把 SOUL 从身体中取出。
- SOUL 与 Kris 身体分离时，玩家仍可操纵 SOUL；Kris 的身体也可以独立行动。
- 这种“输入端 / SOUL / Kris 身体可分离”的现象不止出现一次。
- 因此，“Player 的输入”和“Kris 这个主体”不能当作同一件事。

### Kris 存在不受输入完全支配的行为

- Kris 有玩家无法直接控制、无法完整旁观，或与所选输入不完全一致的行为。
- Kris 的自主行为并不只表现为敌意或暴力；也可以服务于友谊、保护他人等目的。
- 因此，不能把 Kris 简化成 Player 的空白外壳。

### Susie 是 agency 的反例

- Chapter 1 早期 Susie 会拒绝或绕开部分战斗指令；之后又能与队伍合作。
- 同一个角色可以在 refusal / cooperation 之间变化。
- “能否被指挥”不是角色 agency 的固定二元属性。

### Chapter 2 Weird Route

- Weird Route 需要严格的特定操作、回退、战斗结束方式与选择才能维持。
- Player 的输入可通过 Kris 所处的交互链影响 Noelle，并多次越过 Noelle 的拒绝。
- Kris 倒下时，Noelle 仍能感知到命令。
- Noelle 后续明确把某种命令声与 Kris 区分开。
- 这些事实说明“命令来源 / Kris 身体 / Noelle 接收到的控制”并不简单等同。
- 这些事实不证明 Noelle 已理解现实世界 Player 的本体，也不证明 Berdly 已被永久确认死亡。

### Chapter 3 Sword Route

- Sword Route 不以 Chapter 2 Weird Route 为必然前提。
- HERO_SWORD 可以越出通常游戏屏幕，而玩家控制仍暂时留在 HERO_SWORD 上；Kris 身体与当前受控对象因此分离。
- 在相关分支中，Kris 会主动把 Susie 拉开；Susie 也能介入并破坏控制链。
- 因此，“Player controls Kris”不是永远不变的一条单线关系。

### Chapter 4 Weird Route

- SOUL 可以通过 choice / vent 等空间机制重新进入 Kris。
- 某些时点需要及时重入，否则路线会中止。
- Kris 会出现与所选输入不完全一致或抵抗性的可见行为。
- Noelle 会对异常声音 / 内心信息作出反应。
- “恢复控制”在游戏中可以被表现为具体的空间和身体事件，而不只是抽象菜单状态。

### Chapter 5 Weird Route

- 开局推动 Kris 起身需要重复输入，Kris 的行动明显迟缓；具体原因未被明说。
- Noelle 会主动把 Kris 引向湖，并主动索要“命令”。
- 前几组 Stop 选择有独立回应与计数，但并不会立即逆转当前推进方向。
- 后续选项会进一步收窄，出现两侧均为 Proceed 的情况。
- 再往后存在持续输入要求；停止/超时可以进入保留异常后果的后续状态。
- 成功推进后，章节被提前截断并出现 Chapter 7 Side B 的系统要求。
- 这些事实不等于 Side B 已经脱离 Prophecy，也不允许推演尚未公开的后续剧情。

### Prophecy / ending

- Prophecy 在游戏世界内真实存在，并对角色产生约束与预期。
- Ralsei 对 Prophecy 有比早期展示给玩家更多的信息；但这不证明 Ralsei 是管理员或全知角色。
- 官方 FAQ 仍以 “One” 回答 endings，同时明确提醒“抵达结局”不是衡量选择意义的唯一尺度。
- “一个 ending”不等于“所有选择都没有意义”。

## 2. 项目固定公理：后续讨论默认成立，但不伪装成 canon 原句

### A. Player 没有占有 Kris 的自由意志

本项目将“Player 能控制的部分”与“Kris 的自由意志”分开。

默认模型：

**Player 可以影响/劫持 Kris 的部分行动接口与身体执行，但没有进入、替代或拥有 Kris 的自由意志。**

Kris 是“被动接受控制”和“主动反抗控制”的统一体。  
SOUL 离体不是“自由意志突然出现”，而更接近身体执行权与输入端发生分离。

### B. Kris 对 Player 本身的态度：未知

可以确认 Kris 多次排斥某些控制、输入或介入。  
不能据此锁死：

- Kris 憎恨现实 Player；
- Kris 喜欢 Player；
- Kris 依赖 Player 才能存在；
- Kris 已完全理解 Player 的本体。

后续讨论必须允许这些问题保持开放。

### C. “世界意志”是否存在：未知

项目暂不假定 Deltarune 世界存在一个统一、人格化、主动修正异常的“世界意志”。

目前只承认这些可观察结构：

- Story / chapter
- Route conditions
- Prophecy
- menus / choices
- system responses
- implemented boundaries

如果以后讨论“世界意志”，必须明确它是 THEORY，而不是事实底座。

### D. Weird Route 是 Player 主动选择进入的崩坏之路

Player 亲手选择并维持 Proceed / Weird 条件，因此 Weird Route 不是单纯“世界自己坏掉”。

本项目固定理解：

**Player 主动追求异常路径；随着路线深入，正常的角色关系、控制关系和游戏结构逐渐失稳。**

至于最后究竟是 Player 变得更强、还是更失去结果所有权，目前保持开放。

### E. 自由是分层的

本项目固定接受两层同时成立：

1. **Player 相对于 Kris 更自由**：Player 可以停止输入、离开游戏、重新开始。
2. **Player 的游戏内自由仍只能通过已实现的 Route / Chapter / interface 发生。**

因此后续不把“自由”处理成简单的有/无二元值，而讨论“相对于哪一层边界”。

## 3. 《world.execute(me);》最低固定理解

这些是歌词转译公理，不是 DELTARUNE canon。

### Execution

保留至少两层意思，不提前锁死：

1. **execution = run / execute a process / 执行命令**
2. **execution = 强制执行 / 处决**

第一次出现时优先保留中性“执行”的含义；后半只有在剧情与语境需要时才让“处决”含义浮现。

### 数学段

不要求每个数学词都强行对应具体剧情事件。

最低理解：

**Player 所能接触的是一个可描述、可计算、可操作的 Kris 的外层模型；可建模不等于拥有主体本身。**

数学、AC/DC、AD/BC、eggplant/tomato/cat、gender、S/M、多语言计数等，如果没有可靠剧情对应，可以留给后续视觉语言、转场和艺术加工，不强造 lore。

### Freedom

歌词的 “you are free / I am trapped” 在本项目中优先读为：

**Player 能离开；Kris 不能离开自己的世界。**

然后再保留第二层：

**Player 只要继续玩，行动仍必须通过游戏已有的接口和路线。**

## 4. 明确不作为底座的结论

以下全部保持 UNKNOWN / THEORY，不能在后续讨论中偷偷当成前提：

- Kris 明确认识现实世界 Player。
- Kris 明确憎恨 Player 本身。
- SOUL 已被证明就是现实 Player 的完整本体。
- Kris 没有 Player 就无法存在。
- Vessel 就是 Kris，或 Vessel 已被确认会回归。
- Noelle 主动索求命令 = Noelle 已获得自由。
- Berdly 已被 canon 永久确认死亡。
- Sword Route 是 Snowgrave 的必然连续后继。
- Light World = 自由，Dark World = 被控制。
- 切断 strings 就等于自由。
- Ralsei 是管理员 / 幕后控制者。
- Gaster 是所有 UI、Story、Prophecy 的确定主人。
- Side B 已经逃离 Prophecy。
- “一个 ending”意味着所有选择无意义。
- Story / Prophecy 已被证明具有统一人格和意志。
- Chapter 7 / Side B 的具体未来剧情。

## 5. 后续讨论纪律

后续剧情分析统一按以下优先级：

**游戏内直接事实 > 官方文本 > 可重复验证机制 > 强推论 > 理论 > 创作解释**

如果一个歌词句子无法自然与 DELTARUNE 剧情挂钩：

> **不强行解释。**

允许它只承担节奏、视觉语言、图形、转场、色彩、状态切换或艺术隐喻。

如果未来新证据推翻本文件中的事实项，修改本文件；  
如果只是出现更有趣的新理论，不修改本文件，只在讨论中保留开放性。

## 6. 核心问题

后续所有讨论都应能回到这些最小问题，而不是预设答案：

- Player 到底能控制什么，不能控制什么？
- Kris 的自由意志如何穿透或绕开行动接口？
- 当控制扩散到 Noelle、HERO_SWORD 等第三者时，谁是 executor，谁是 executable？
- Player 主动进入 Weird Route 后，究竟破坏了什么？
- 当 Player 自己也只能通过 Route / Chapter / interface 行动时，“自由”究竟属于哪一层？

**Who executes whom?**
