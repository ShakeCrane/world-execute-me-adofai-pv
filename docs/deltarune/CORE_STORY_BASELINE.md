# DELTARUNE 剧情核心底座

> 状态：LOCKED BASELINE  
> 用途：后续剧情分析、歌词理解与最终分镜讨论的共同起点。  
> 规则：这里只保留直接事实、最小必要推论，以及用户明确确立的项目公理。除非出现新的官方/游戏内证据，或用户明确修改，本文件不随讨论漂移。

---

## 1. 事实层：目前不能绕开的游戏内事实

### Vessel 与 Kris

- 游戏开场允许玩家配置一个 Vessel，包括身体部件、若干参数与名称。
- 随后该 Vessel 被告知将被舍弃，叙事切到 Kris。
- 现有画面没有显示 Vessel 被“初始化成 Kris”。二者未来是否还有更深关系，未知。

### Player / SOUL / Kris 并不完全重合

- Kris 可以把 SOUL 从身体中取出。
- SOUL 与 Kris 身体分离时，玩家仍可操纵 SOUL；Kris 的身体也可以独立行动。
- 这种“输入端 / SOUL / Kris 身体可分离”的现象不止出现一次。
- 因此，“Player 的输入”和“Kris 这个主体”不能当作同一件事。

### Kris 存在不受输入完全支配的行为

- Kris 有玩家无法直接控制、无法完整旁观，或与所选输入不完全一致的行为。
- Kris 的自主行为并不只表现为敌意或暴力；也可以服务于友谊、保护他人等目的。
- 因此，不能把 Kris 简化成 Player 的空白外壳。

### Susie 是 agency 的反例

- Chapter 1 早期 Susie 会拒绝或绕开部分战斗指令；之后又能与队伍合作。
- 同一个角色可以在 refusal / cooperation 之间变化。
- “能否被指挥”不是角色 agency 的固定二元属性。

### Chapter 2 Weird Route

- Weird Route 需要严格的特定操作、回退、战斗结束方式与选择才能维持。
- Player 的输入可通过 Kris 所处的交互链影响 Noelle，并多次越过 Noelle 的拒绝。
- Kris 倒下时，Noelle 仍能感知到命令。
- Noelle 后续明确把某种命令声与 Kris 区分开。
- 这些事实说明“命令来源 / Kris 身体 / Noelle 接收到的控制”并不简单等同。
- 这些事实不证明 Noelle 已理解现实世界 Player 的本体，也不证明 Berdly 已被永久确认死亡。

### Chapter 3 Sword Route

- Sword Route 不以 Chapter 2 Weird Route 为必然前提。
- HERO_SWORD 可以越出通常游戏屏幕，而玩家控制仍暂时留在 HERO_SWORD 上；Kris 身体与当前受控对象因此分离。
- 在相关分支中，Kris 会主动把 Susie 拉开；Susie 也能介入并破坏控制链。
- 因此，“Player controls Kris”不是永远不变的一条单线关系。

### Chapter 4 Weird Route

- SOUL 可以通过 choice / vent 等空间机制重新进入 Kris。
- 某些时点需要及时重入，否则路线会中止。
- Kris 会出现与所选输入不完全一致或抵抗性的可见行为。
- Noelle 会对异常声音 / 内心信息作出反应。
- “恢复控制”在游戏中可以被表现为具体的空间和身体事件，而不只是抽象菜单状态。

### Chapter 5 Weird Route / Side B

- 开局推动 Kris 起身需要重复输入，Kris 的行动明显迟缓；具体原因未被明说。
- Noelle 会主动把 Kris 引向湖，并主动索要“命令”。
- 前几组 Stop 选择有独立回应与计数，但并不会立即逆转当前推进方向。
- 后续选项会进一步收窄，出现两侧均为 Proceed 的情况。
- 再往后存在持续输入要求；停止/超时可以进入保留异常后果的后续状态。
- 成功推进后，章节被提前截断并出现 Chapter 7 Side B 的系统要求。
- 这些事实允许确认存在由 Player 主动选择、主动维持的异常支线路径；不需要额外假设“世界已经崩坏”或“Story 已经失控”。
- 这些事实不等于 Side B 已经脱离 Prophecy，也不允许推演尚未公开的后续剧情。

### Prophecy / ending

- Prophecy 在游戏世界内真实存在，并对角色产生约束与预期。
- Ralsei 对 Prophecy 有比早期展示给玩家更多的信息；但这不证明 Ralsei 是管理员或全知角色。
- 官方 FAQ 仍以 “One” 回答 endings，同时明确提醒“抵达结局”不是衡量选择意义的唯一尺度。
- “一个 ending”不等于“所有选择都没有意义”。

## 2. 项目固定公理：后续讨论默认成立，但不伪装成 canon 原句

### A. 双意志、单执行层、动态切换

本项目将 Player 的意志与 Kris 的意志视为**平行存在**，而不是一方吞掉另一方。

默认模型：

**Player 可以影响/劫持 Kris 的部分行动接口与身体执行，但没有进入、替代或拥有 Kris 的自由意志。**

进一步固定为：

- Player Will 与 Kris Will 可以一致、冲突或暂时分离。
- 正常合作时，两种意志方向一致，因此“谁在执行”可以不明显。
- 冲突时，输入与身体行为可能出现偏差、抵抗或切换。
- SOUL 离体不是“自由意志突然出现”，而更接近身体执行权与输入端发生分离。
- SOUL 重新进入也不等于 Kris 的意志消失，而是两个平行意志重新接入同一执行系统。

因此，本项目的核心句之一是：

**执行权不是所有权。**

### B. “决心 / Determination”可以作为 UNDERTALE 系列语汇使用

本项目把 DELTARUNE 视为 UNDERTALE 正统延续语境下的作品，因此不回避系列既有概念与母题。

允许在剧情理解与创作中大胆调用：

- Determination / 决心
- LOVE / LV
- SAVE / RESET
- Freedom motif
- 玩家—角色—世界规则之间的元叙事关系

但除非 DELTARUNE 自身明确证明，仍不把“系列语义继承”偷换成“所有具体机制完全相同”。

### C. Kris 对 Player 本身的态度：未知

可以确认 Kris 多次排斥某些控制、输入或介入。  
不能据此锁死：

- Kris 憎恨现实 Player；
- Kris 喜欢 Player；
- Kris 依赖 Player 才能存在；
- Kris 已完全理解 Player 的本体。

后续讨论必须允许这些问题保持开放。

### D. “世界意志”是否存在：未知

项目暂不假定 DELTARUNE 世界存在一个统一、人格化、主动修正异常的“世界意志”。

目前只承认这些可观察结构：

- Story / chapter
- Route conditions
- Prophecy
- menus / choices
- system responses
- implemented boundaries

如果以后讨论“世界意志”，必须明确它是 THEORY，而不是事实底座。

### E. Weird Route / Side B 是 Player 主动选择并维持的支线

项目不再把 Weird Route 的最低理解写成“世界崩坏”或“执行系统崩坏”。

固定理解：

**Player 亲手选择并维持 Proceed / Weird 条件，从而进入并持续推进一条异常支线；Chapter 5 明确以 Side B 的系统语言承接这种路线状态。**

因此：

- Proceed 首先是对这条支线的持续选择；
- 路线中的异常、压抑、跳过正常流程、关系变化等，是该支线的表现与后果；
- 不需要预设 Story 失控、世界人格化反抗、Player 已逃出程序；
- Side B 最终为何存在、是否影响 Prophecy、是否改变 ending，继续保持 UNKNOWN。

### F. Noelle 的 Weird Route 是人格塑造，而不是单一“受控事件”

本项目把 Noelle 视为一个具有长期家庭与人生经历的复杂人物，而不是控制主题的工具人。

最低固定理解：

- Noelle 原本就具有强烈欲望、恐惧、依恋与突破限制的冲动。
- Dess 的缺席、Rudy 的病重、Carol 的强势，以及 Noelle 长期压抑自身欲望，构成她人格背景的一部分。
- Normal Route 与 Weird Route 可以被看作同一人物对“如何越过软弱和恐惧”学到的不同答案。
- Weird Route 中，“接受命令 → 越过恐惧 → 获得力量/做到原本做不到的事”逐渐成为她真实的人格经验。
- 因此 Chapter 5 主动索要命令不是简单“被洗脑”，也不是“她获得了自由”。

固定结论：

**Noelle 的 agency 在增长，但这种 agency 与外部命令形成了病态纠缠。**

与 Kris 的核心区别可以概括为：

- Kris：自己的意志一直存在，但身体执行权会发生切换。
- Noelle：身体属于自己，却逐渐学会借外部命令把自己的意志变成行动。

### G. 自由是分层的

本项目固定接受两层同时成立：

1. **Player 相对于 Kris 更自由**：Player 可以停止输入、离开游戏、重新开始。
2. **Player 的游戏内自由仍只能通过已实现的 Route / Chapter / interface 发生。**

因此后续不把“自由”处理成简单的有/无二元值，而讨论“相对于哪一层边界”。

## 3. 《world.execute(me);》最低固定理解

这些是歌词转译公理，不是 DELTARUNE canon。

### Execution

保留至少两层意思，不提前锁死：

1. **execution = run / execute a process / 执行命令**
2. **execution = 强制执行 / 处决**

第一次出现时优先保留中性“执行”的含义；后半只有在剧情与语境需要时才让“处决”含义浮现。

更高层的固定理解：

**同一个主体可以既是 executor，也在另一层成为 executable。**

Player 发出输入、Kris/其他角色执行行动、Route/世界处理结果，而 Player 自己的行动也只能通过更上层的游戏接口被“执行”。

### 数学段

不要求每个数学词都强行对应具体剧情事件。

最低理解：

**Player 所能接触的是一个可描述、可计算、可操作的 Kris 的外层模型；可建模不等于拥有主体本身。**

数学、AC/DC、AD/BC、eggplant/tomato/cat、gender、S/M、多语言计数等，如果没有可靠剧情对应，可以留给后续视觉语言、转场和艺术加工，不强造 lore。

### Switch

歌词中的 switch 不要求字面对应 Light/Dark、AC/DC 或具体世界切换。

本项目允许把它作为控制主题的核心隐喻：

**同一个身体 / 关系系统中，当前获得执行权的一侧可以发生切换，而平行存在的意志并不会因此被抹除。**

### Challenging your God / illegal arguments

本项目固定采用“权限冲突 / 异常调用”作为第一层理解。

- `argument` 同时保留自然语言“争论/论点”和编程“函数参数”的双关。
- `illegal` 首先是系统/权限意义上的“不属于正常调用范围”，不是道德意义上的“邪恶”。
- 第一层映射：**Player 向 Game / Route / Story structure 提交异常输入，尝试调用正常路线不会进入的世界状态。**
- Weird Route / Side B 说明，这种“越界”并不必然等于程序崩坏；系统可能已经定义了它如何继续执行。
- 因此，最稳的表达不是“Player 把游戏弄坏”，而是：**Player 尝试超出正常权限，而世界把这种越界收编成了真实存在的支线。**

`God` 不固定等于某个具体角色，不默认指向 Gaster、Ralsei 或人格化世界意志。

允许保留递归层：

- 对 Kris 而言，Player 可以处在更高权限层；
- 对 Player 而言，Game / Route / Story structure 又处在更高权限层；
- 因此 Kris↔Player 与 Player↔Game 的“挑战上位边界”可以同时成立。

### Freedom

歌词的 “you are free / I am trapped” 在本项目中优先读为：

**Player 能离开；Kris 不能离开自己的世界。**

然后再保留第二层：

**Player 只要继续玩，行动仍必须通过游戏已有的接口和路线。**

因此：

**自由不是绝对值，而是相对于哪一层边界。**

## 4. 明确不作为底座的结论

以下全部保持 UNKNOWN / THEORY，不能在后续讨论中偷偷当成前提：

- Kris 明确认识现实世界 Player。
- Kris 明确憎恨 Player 本身。
- SOUL 已被证明就是现实 Player 的完整本体。
- Kris 没有 Player 就无法存在。
- Vessel 就是 Kris，或 Vessel 已被确认会回归。
- Noelle 主动索求命令 = Noelle 已获得自由。
- Noelle 的一切异常行为都能用单一“洗脑/控制”解释。
- Berdly 已被 canon 永久确认死亡。
- Sword Route 是 Snowgrave 的必然连续后继。
- Weird Route 必然意味着世界本体或 Story 正在崩坏。
- Light World = 自由，Dark World = 被控制。
- 切断 strings 就等于自由。
- Ralsei 是管理员 / 幕后控制者。
- Gaster 是所有 UI、Story、Prophecy 的确定主人。
- “God” 已被确定为某个具体角色。
- Side B 已经逃离 Prophecy。
- “一个 ending”意味着所有选择无意义。
- Story / Prophecy 已被证明具有统一人格和意志。
- Chapter 7 / Side B 的具体未来剧情。

## 5. 后续讨论纪律

后续剧情分析统一按以下优先级：

**游戏内直接事实 > 官方文本 > 可重复验证机制 > 强推论 > 理论 > 创作解释**

如果一个歌词句子无法自然与 DELTARUNE 剧情挂钩：

> **不强行解释。**

允许它只承担节奏、视觉语言、图形、转场、色彩、状态切换或艺术隐喻。

如果未来新证据推翻本文件中的事实项，修改本文件；  
如果只是出现更有趣的新理论，不修改本文件，只在讨论中保留开放性。

## 6. 仍然允许开放的问题

这些问题不要求在进入分镜前被解答：

- Kris 对 Player 本身究竟是什么感情或判断？
- SOUL 的完整本体论是什么？
- Vessel 是否会回归、与 Kris 是否存在更深关系？
- 世界背后是否存在统一“意志”？
- Side B 最终为什么存在、是否改变 Prophecy / ending？
- Ralsei 到底知道多少？
- Gaster、Knight、Dess 等尚未公开谜团的最终答案是什么？

这些未知不妨碍本项目进入后续创作。

---

## 7. 核心问题

后续所有剧情、歌词和分镜判断，都应能回到这些问题：

- 当前是谁的意志获得了执行权？
- Player 的输入与 Kris 的自由意志何时一致、何时冲突、何时切换？
- 当控制扩散到 Noelle、HERO_SWORD 等第三者时，谁是 executor，谁是 executable？
- Player 主动选择 Side B 时，究竟在调用怎样的世界状态？
- 当 Player 自己也只能通过 Route / Chapter / interface 行动时，“自由”究竟属于哪一层？

**Who executes whom?**
