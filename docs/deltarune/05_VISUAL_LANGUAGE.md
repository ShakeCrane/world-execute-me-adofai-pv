# 视觉语言与素材计划

导演版v0.1。继承原作左主体pane/外部输入/右世界结构，但观众应先读到Kris的身体和行为，再读命令。画布1280×720、24fps；主体pane约x24–384/y56–604，世界x404–1164；底部616–680歌词/留白。新DR控制窗不复用DeepSeek品牌CSS，沿用分层逻辑和透明载体。

## 图形 grammar

| 元素 | 固定规则 | 可变语义/边界 |
|---|---|---|
| SOUL | 原创程序化红心、硬边、与游戏heart意象对应；同一shot只一颗主要input心 | 可在menu/身体/隔离层移动；不打“Player soul”标签；Ch5渐白只能短暂遮弱，仍看清选择过程 |
| Kris | 暗发遮眼、横条纹衣/披风的原创简化轮廓；先用几何study，不从游戏导出sprite | 标记主体而非最终角色画风；手、肩、朝向给独立意向；任何微笑/颤抖须有来源或标作者情绪设计 |
| Choice | 黑底白边、稀疏选项、红心selector；字体用现有合法本机/OFL，不打包游戏font | 拒绝/重试/两项同文/四项空白必须分开；如果玩家可退出，不把stop图形彻底删到无路可选 |
| Dialogue | 白框、左侧speaker锚点；游戏短词与作者关系标记分开 | 不伪造Kris关于Player的独白；不写长原文对白；具体游戏转录以后按版本核对 |
| Battle menu | FIGHT/ACT/ITEM/SPARE 的选择位置/色彩意象程序化，非逐像素复制 | 早期Susie的auto FIGHT与后期合作切换有差异；词无关主题时隐藏 |
| SAVE | 单slot卡、名字与指针层可分 | 只表现E02可见名字覆盖和状态延续；不存在官方route memory总表，不让角色看历史log |
| Chapter / route | 作者小型外框或路径标记；调研ID只在metadata | 不能在作品流里摆E编号/证据等级；SideB终屏含游戏短提示但不仿官方启动品牌 |
| Light World | 暖灰/深绿、地面与室内实体边界 | 普通关系/友情的温度；不等于无控制 |
| Dark World | 靛蓝/黑、青色窄光、网格稀疏 | 世界深度，非“AI内部”；像素网格不能处处发光 |
| Weird deviation | 冰白、失去暖色、路径反折、留一空位；ring为红裂纹意象 | 有路线事件才改变，避免每次唱词glitch；红不是Player邪恶色码，而是SOUL/冲突两用 |
| Strings / connection | 输入至身体的细红线；角色至世界可用白线；约束外框用灰白 | 连线本身是作者关系图，不声称每个人有实物strings；只有NEO镜头用实际线意象 |
| Refusal | 心动、身体不动，命令文本停住；或身体行动与输入箭头分离 | 保留局部自主，不等于彻底逃离；避免红眼/恶笑自动表意 |
| Story boundary | 白框外有更大白框，选项重复/章节断点 | 不是有脸反派；框从支持阅读变为限制，角色也可能主动走向它 |
| Player presence | 没有脸、手持刀或拟人恶魔；从屏外输入/selector体现 | 输入节奏可急/迟疑/停；关界面只是出口隐喻，不声称游戏能强制现实人按键 |

## 调色与可读性

主黑 `#070A14`；主体衣绿 `#75A58B` / Dark青 `#6DD2DC`；框白 `#E7E9F2`；SOUL红 `#F04462`；友情暖 `#D5BE8A`；冰 `#C7E4EC`；文字灰 `#8C91A4`。每镜最多1个主要红心+1条关键连接+2组短文字。glow用于连接接触，不用白雾遮掉动作。全宽世界占画布不能自动代表自由，外框可随后显现。

主视线从左输入→Kris→右世界，反转时先让角色的手到menu，再让menu落入更外的框；使用位置和动作揭露，少写解释。底部歌词由本地原时间线渲染；PoC只放作者短状态/留白，不拿语义概要当歌词。
